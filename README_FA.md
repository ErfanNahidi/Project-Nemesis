## ⚡ نمای کلی

**Project Nemesis** یک داشبورد آموزشی و ماژولار برای تست نفوذ است که بر روی **امنیت سرویس‌های ویندوز** متمرکز می‌باشد.  
این پروژه یک رابط خط فرمان یکپارچه برای کشف، دریافت، به‌روزرسانی و اجرای مجموعه‌ای از ابزارهای تهاجمی امنیتی فراهم می‌کند – هرکدام یک پروتکل یا بردار حمله خاص را هدف قرار می‌دهند.

تمامی ابزارها برای **محیط‌های آزمایشگاهی ایزوله** طراحی شده‌اند و **فقط برای آموزش امنیتی مجاز** در نظر گرفته شده‌اند.

---

## 🧩 ویژگی‌ها

- 🖥️ **داشبورد تعاملی** – رابط کاربری ترمینال تمیز با منوهای رنگی
- 🧰 **مجموعه ابزار ماژولار** – اسکنر، DHCP Havoc، DoS، sniffer، حملات AD/SMB/DNS
- 📦 **دریافت با یک کلیک** – هر ابزار به‌طور خودکار از مخزن گیت‌هاب خود دریافت می‌شود
- 🔄 **به‌روزرسانی آسان** – هر ماژول را می‌توان با clone مجدد به آخرین نسخه ارتقا داد
- 🔗 **راه‌انداز سراسری سیستم** – فرمان `nemesis` به‌صورت اختیاری در همه جا در دسترس است
- 🎓 **تمرکز آموزشی** – ساخته شده برای یادگیری، نه استفاده در محیط عملیاتی

## 🚀 شروع سریع

```bash
# دریافت داشبورد
git clone https://github.com/ErfanNahidi/Project-Nemesis.git
cd Project-Nemesis

# قابل اجرا کردن
chmod +x nemesis.sh

# اجرا
./nemesis.sh
```

> 💡 **نکته:** از راه‌انداز داخلی برای نصب فرمان سراسری `nemesis` استفاده کنید.


### زیرمنوی حملات عمومی

```
  [1] Scanner          – شناسایی شبکه و نگاشت CVE
  [2] DHCP Havoc       – exhaustion DHCP / سرور جعلی
  [3] DoS              – تست انکار سرویس
  [4] Sniffer          – ضبط و تحلیل بسته‌ها
  [5] AD Reaper        – شمارش Active Directory (به‌زودی)
  [6] SMB Phantom      – شمارش/بهره‌برداری SMB (به‌زودی)
  [7] DNS              – جعل DNS / مسمومیت کش
  [8] RCP              – (رزرو شده برای حملات RPC آینده)
```

## 🔧 روند کار ماژول‌ها

1. **یک ابزار** را از منو انتخاب کنید.  
2. اگر هنوز دریافت نشده باشد → به‌طور خودکار از گیت‌هاب در پوشهٔ `modules/` دریافت می‌شود.  
3. وابستگی‌های پایتون ابزار به‌طور خودکار نصب می‌شوند.  
4. می‌توانید ابزار را **اجرا** کنید یا بعداً برای دریافت به‌روزرسانی **clone مجدد** نمایید.

تمامی ابزارها با دستور زیر اجرا می‌شوند:

```bash
sudo python3 <module>/cli.py
```

---

## 📦 وابستگی‌ها

- **bash** ≥ نسخه ۴.۰
- **git**
- **python3** و **pip3** (برای ابزارهای جداگانه)
- دسترسی **sudo** (ابزارهای شبکه نیاز به root دارند)

خود داشبورد **هیچ وابستگی خارجی** ندارد.

## 🔄 به‌روزرسانی داشبورد

از راه‌انداز داخلی استفاده کنید:

1. از منوی اصلی، به **[1] راه‌انداز Nemesis** بروید.  
2. گزینهٔ **[3] به‌روزرسانی** را انتخاب کنید – آخرین کد داشبورد را از گیت‌هاب دریافت می‌کند.

یا به‌صورت دستی:  
```bash
git pull origin main
```
